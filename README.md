# Customer Churn Analysis

An end-to-end customer churn analysis project using **Python, SQL Server, and Power BI** to investigate customer churn patterns and identify customer segments associated with higher churn.

The analysis covers **7,043 telecommunications customers** and examines factors such as contract type, tenure, monthly charges, internet service, payment method, and technical support.

Key findings were translated into **customer risk segments and business recommendations** to support targeted customer retention strategies.

### Tools

* Python & Pandas
* SQL Server
* Power BI
